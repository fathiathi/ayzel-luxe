# AYZEL LUXE 👗

A Luxury Ladies Fashion E-Commerce Website.

## 🌸 About the Project
AYZEL LUXE is a modern and elegant online fashion store designed for ladies to explore and shop beautiful outfits.

## ✨ Features
- Home page
- Product collections
- Product search and sorting
- Add to cart
- Shopping cart
- Login and Signup pages
- Checkout demo
- Order success page
- Responsive design
- WhatsApp contact

## 💻 Technologies Used
- HTML
- CSS
- JavaScript
- Local Storage
